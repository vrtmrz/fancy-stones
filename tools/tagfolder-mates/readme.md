## TagFolder Mates

Create actual files from the list which were generated by
`Dumping tags for reporting bugs` on
[TagFolder](https://github.com/vrtmrz/obsidian-tagfolder).

### Prerequisites

- [Deno](https://deno.land/) installed on your system.
- A `tags.txt` file containing the list of tags, which can be generated from
  TagFolder.

### Usage

1. Prepare a list of tags from TagFolder. You can use the
   `Dumping tags for reporting bugs` button in the settings of TagFolder to
   generate this list, which will be saved in your clipboard.
2. Paste the list into a `tags.txt` file.
3. Run the script with the command:
   ```bash
   deno task main
   ```
4. The script will create a folder named `dump-<timestamp>` in the `out`
   directory. We can address to the reported issue with actual file
   circumstances.
